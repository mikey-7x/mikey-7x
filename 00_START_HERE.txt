HOW TO UPLOAD (GitHub website, on Android)
------------------------------------------
1. Open https://github.com/mikey-7x/mikey-7x
2. Tap "Add file", then "Upload files".
3. Batch A - root files: README.md, LICENSE, NOTICE.md, .gitattributes,
   .gitignore. (Dotfiles are easier with method in step 5.)
4. Batch B - assets: profile-banner.png, introduction-poster.png,
   introduction-poster.pdf, powered-by-mikey-hexoid-sys.png,
   powered-by-mikey-hexoid-sys.svg, mikey-hexoid-sys-mark.png,
   mikey-hexoid-sys-mark.svg, README.md, SHA256SUMS.
   Type "assets/" in the file-name box, then drag the files in.
5. Batch C - tools: make_banner.py, make_poster.py, verify_profile.py.
   Type "tools/" in the file-name box first.
6. Dotfiles and workflow - tap "Add file", then "Create new file", and type the
   full path in the name box:
     .gitattributes
     .gitignore
     .github/workflows/verify.yml
   Paste the content of each file, then tap "Commit changes".
7. Commit directly to main.
8. Open the "Actions" tab. The "Profile checks" run should be green.

If an old file already exists, upload the new version over it - the poster files
are new, the rest are replacements.
